# 文学少女風 三題噺 アーカイブ

@ryo_miu の三題噺を、新しい順に読み返すための静的な一覧です。作品名・お題・本歌・冒頭で検索でき、月から絞り込めます。各作品から、元の投稿を開けます。

収録しているのは投稿記録で確認できた作品だけです。過去の全件を保証するものではありません。日時は記録上の投稿時刻（日本時間）です。

## 閲覧する

1. このリポジトリを手元に取得します。
2. `index.html` をブラウザで開きます。

検索と月の絞り込みは、そのページの中で動きます。ビルドや外部の配信設定は要りません。

フォルダを手元の簡易サーバで見る場合は、リポジトリの直下で次を実行します。

```
python3 -m http.server
```

ブラウザで `http://127.0.0.1:8000/` を開きます。

## 作品を追加する

`works.js` の `SANDAIBANASHI_WORKS` 配列の先頭へ、1作品ぶんのオブジェクトを足します。並びは新しい順です。

```javascript
{
  "postedAt": "2026-11-07 17:15",
  "title": "作品名",
  "themes": "お題1・お題2・お題3",
  "honka": "本歌",
  "statusId": "投稿ID",
  "opening": "",
  "note": ""
}
```

- `postedAt` は記録上の投稿時刻（日本時間）で、`YYYY-MM-DD HH:mm` と書きます。
- `title`、`themes`、`honka`、`opening` は、記録にある文をそのまま書きます。本文は書き換えず、記録にない項目は埋めません。
- `opening` は本文の冒頭です。記録に無いときは `""` のままにします。
- `statusId` は `https://x.com/ryo_miu/status/` の後ろの数字です。
- `note` は、再投稿であるなど記録にある補足だけを書きます。無ければ `""` です。
- 収録数、期間、最新の作品、月の選択肢は、この配列から作られます。

ヘッダー画像は `assets/header.jpg` です。差し替えるときは、同じパスのJPEGを置き換えます。
